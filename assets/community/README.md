# 커뮤니티 사진 넣는 곳

팀원 책상 사진을 아래 이름으로 이 폴더에 올리면 커뮤니티 게시물 사진이 바로 바뀝니다 (코드 수정 없음).

| 파일 이름 | 들어가는 게시물 |
|---|---|
| `post-1.jpg` | 퇴근 후, 나만의 작은 서재 (우드톤) |
| `post-2.jpg` | 작은 책상도 충분하니까 (미니멀) |
| `post-3.jpg` | 아이디어가 떠오르는 오후 (크리에이티브) |

- `.png`도 됩니다 (`post-1.png`). 가로 사진, 긴 변 1600px 정도면 충분해요.
- 사진이 없으면 프리셋 3D 렌더 이미지가 대신 나옵니다.
- 제품 사진은 `assets/products/monitor.jpg`, `lamp.jpg`, `keyboard.jpg`, `shelf.jpg` 이름으로 넣으면 같은 방식으로 바뀝니다. 브랜드 로고가 크게 보이지 않는 무료 사진(Unsplash, Pexels 등)을 쓰세요.
